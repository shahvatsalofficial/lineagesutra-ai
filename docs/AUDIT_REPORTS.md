# Audit reports

`lineagesutra audit` is the tool auditing itself (and optionally your SQL folder) and writing the result as **Markdown, HTML and JSON** so humans and machines can read it.

```bash
npx lineagesutra-ai audit --out audit-out                 # the tool, using bundled fixtures
npx lineagesutra-ai audit --root ./sql --out audit-out    # plus a scan audit of your repository
npx lineagesutra-ai audit --out audit-out --with-tests    # plus a live run of the test suite
```

Files: `audit-report.html` (self-contained, accessible, responsive, light/dark, printable), `audit-report.md`, `audit-report.json` (sealed; check with `lineagesutra verify`). An existing report is not overwritten without `--force`. Exit code is `0` on PASS and `1` on FAIL.

## Sections

| Section | What is measured |
|---|---|
| Lineage accuracy | Every gold case scored on exact edge sets plus required warnings; micro precision/recall with 95% Wilson intervals; pass rate per tag |
| Safety, integrity, adversarial inputs | Read-only (tree hash before/after), determinism, file-order independence, tamper detection, monotonic impact, symlink and size limits, comment-injection, ambiguity handling, 3,000-input seeded fuzz, deep nesting, 5,000-column table, no network/subprocess code in core, XSS escaping |
| Performance | Scan of 2,000 chained views over 50 tables (median of 3), impact on a 20,000-dataset graph (median of 5), machine and Node version printed |
| Package and skill integrity | 25 skills with matching names, 20 role files, schemas parse, workflows and rules present, no credentials in the tree |
| Repository (with `--root`) | Parser coverage, warnings by kind, sensitivity name hints |
| Test suite (with `--with-tests`) | Counts from a real `node --test` run |
| What was NOT verified | Always present: SQLGlot, live database, native IDE activation, MCP Inspector, third-party review, report signing |

## Reading a report

- `PASS` means every executed check passed. `NOT_RUN` entries are deliberate gaps, not passes.
- The accuracy numbers describe the bundled gold corpus. They do **not** predict accuracy on your SQL; the `--root` section does show how much of *your* SQL was parsed.
- Re-run it. The report prints the commands to reproduce itself.
