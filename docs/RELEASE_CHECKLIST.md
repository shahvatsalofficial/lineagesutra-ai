# Open-source release checklist

- [ ] Creator attribution to Vatsal Shah preserved in code/docs/metadata.
- [ ] GitHub/npm/domain/trademark uniqueness checked, without legal guarantee.
- [ ] Unit and integration tests executed; no fabricated CI claims.
- [ ] Windows, macOS and Linux CI results inspected separately.
- [ ] SQL dialect support matrix and parser version pinned.
- [ ] Verified source seals and reproducibility fixtures published with no real private data.
- [ ] Dependencies licenses, vulnerability scans, SBOM and privacy boundaries reviewed.
- [ ] A supported IDE can load a skill in a real native session, demonstrated.
- [ ] A malicious input/symlink/secret regression test has been executed.
- [ ] API/data-schema backward compatibility reviewed.
- [ ] No production database access by default; authenticated remote hosting independently audited.
- [ ] Limitations in README and landing page match actual capabilities.
