# Contributing to LineageSutra AI

Thanks for helping build safe, verifiable data lineage. Maintainer and original creator: Vatsal Shah.

Before a PR: read SECURITY.md and AGENTS.md, open an issue for API or schema changes, keep tests deterministic and small, add fixture evidence for each supported SQL dialect/construct, label unimplemented coverage, run `npm test` and `npm run demo`, and avoid uploading real production schemas with credentials or personal data.

PRs must state change scope, user impact, actual test output, any not-run checks, backward compatibility and data security changes. Contributions are reviewed by humans. No spam/automated bulk PRs.
