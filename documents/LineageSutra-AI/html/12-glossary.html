Glossary

TermMeaning
LineageWhich inputs a dataset or column is built from
Column-level lineageLineage per column, not just per table
Direct edgeOutput column is a plain copy of an input column
Derived edgeOutput is an expression, aggregate, window or subquery over the input
Indirect edgeInput only decides which rows exist or how they group/order
Confirmed (static)A parsed column path exists; not a database test
PossibleNot proven at field level
Proof pathThe edge list that justifies a finding, with file:line:col
External nodeDataset referenced but not declared in scanned SQL
Gold corpusHand-labelled SQL cases with expected edges
Wilson interval95% confidence interval for a proportion
SealSHA-256 over canonical JSON; tamper evidence
Evidence capsuleA sealed report with sources and hashes
DriftRadarcompare between two scans
