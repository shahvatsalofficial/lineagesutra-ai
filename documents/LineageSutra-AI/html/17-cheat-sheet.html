Commands#

I want toCommand
See the lineage maplineagesutra scan --root ./sql --out lineage.html
Save it for later commandslineagesutra scan --root ./sql --out lineage.json
Know what breakslineagesutra impact --input lineage.json --table T --column C --change rename
Know where a column comes fromlineagesutra upstream --input lineage.json --table T --column C
Compare two versionslineagesutra compare --before a.json --after b.json --fail-on-breaking
Check declared ruleslineagesutra contract --input lineage.json --contract contracts.json
Import dbt metadatalineagesutra dbt --input manifest.json
Check a report was not editedlineagesutra verify --input report.json
Audit the tool or my SQLlineagesutra audit --root ./sql --out audit-out
Give an AI agent safe toolslineagesutra mcp --root ./sql
Install skills for my IDElineagesutra install-skills --ide claude --project .

Output format follows the file extension: .json, .md, .html, .mmd (Mermaid).

Reading the symbols#

You seeMeans
directPlain copy of a column
derivedComputed from a column
indirectColumn only decides which rows exist
supported-subsetParsed from SQL inside the documented subset
possible-indirect / possible-table-levelNot proven at column level
externalReferenced but never declared in scanned SQL
partial / unknownThe parser could not read everything

Turn warnings into zero#

  1. Add the CREATE TABLE statements the views read from.
  2. Replace SELECT * over undeclared tables, or declare them.
  3. Compile dbt models and scan the compiled folder.
  4. Re-run scan --strict.

Limits at a glance#

Static SQL text only. Documented subset, no dialect certified. Contract checks use declared DDL, not production. The seal detects edits; it does not prove authorship. serve is for localhost only.
