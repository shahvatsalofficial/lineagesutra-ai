# Support

- **Questions and ideas:** GitHub Discussions or Issues on https://github.com/shahvatsalofficial/lineagesutra-ai
- **Bugs:** open an issue with the command, `lineagesutra --version`, your Node version and OS, and a **sanitized** minimal SQL sample. An audit report (`lineagesutra audit --out audit-out`) helps.
- **Wrong or missing lineage:** attach the smallest SQL that reproduces it and the edge you expected. Good samples become gold-corpus cases.
- **Security:** see SECURITY.md.

This is a volunteer-maintained project; there is no commercial support or SLA.
